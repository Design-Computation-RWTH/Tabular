## A useful mental model

Tabular describes a research output at two levels:

1. **Column metadata** explains what individual fields mean and which
   quantities and units they use.
2. **Dataset metadata** explains the table as a research object: its title,
   description, licence, dates, contributors, and other profile requirements.

The RO-Crate node packages both levels with the data. Coscine can provide the
dataset metadata requirements for a selected repository resource and receive
the completed package.
